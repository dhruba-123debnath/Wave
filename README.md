# 🎵 WAVE — Full Stack Music Streaming Application

WAVE is a Spotify-inspired full-stack music streaming web application developed using the MERN stack.

The project demonstrates frontend development, backend API integration, database management, and music-related functionality.

##  Tech Stack

**Frontend:** React.js, JavaScript, HTML, CSS, Vite

**Backend:** Node.js, Express.js

**Database:** MongoDB, Mongoose

##  Features

- Spotify-inspired user interface
- User authentication functionality
- Music and album management
- RESTful API development
- MongoDB database integration
- React-based frontend

##  Project Structure

- `complete-backend/` — Backend APIs and database models
- `spotify-react-frontend/` — React frontend application

##  Installation

**Clone the repository:**

```bash
git clone https://github.com/dhruba-123debnath/Wave.git
```

**Install backend dependencies:**

```bash
cd Wave/complete-backend
npm install
```

Configure the required environment variables and start the backend using its configured script.

**Install frontend dependencies:**

From the `Wave` root directory:

```bash
cd spotify-react-frontend/spotify-react-frontend
npm install
npm run dev
```
